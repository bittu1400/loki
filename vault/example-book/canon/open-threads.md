# Open Threads — The Salt Almanac

Planted setups awaiting payoff. Append plus status flip; a thread is never
deleted. Thread IDs are `T-` plus a zero-padded counter, allocated by the
engine and never reused.

Grammar: - `[T-NNN]` `[open]` `[ch-NNN]` <thread>
Flips to: - `[T-NNN]` `[resolved:ch-NNN]` `[ch-NNN]` <thread>
